## Features

- Clean, modern interface
- Records your screen, window, or browser tab
- Live recording timer
- Automatically detects when recording is stopped via the browser's native "Stop Sharing" control
- Automatically downloads the recording as a `.webm` file when stopped
- Runs entirely locally; no data is uploaded anywhere
- No installation, build step, or dependencies required

## Installation

No installation is required. This is a static HTML, CSS, and JavaScript project.

### Quick Start

```bash
# Clone the repository
git clone https://github.com/Binidu01/Screen-Recorder.git

# Navigate to the project directory
cd Screen-Recorder
```

Open `index.html` directly in a browser (double-click the file, or drag it into a browser window).

**Note:** Due to browser security restrictions around screen capture, this application works when opened via `file://`, or when served over `http(s)://` or `localhost`. It will not function inside a sandboxed iframe.

## Usage

1. Open `index.html` in Chrome, Edge, or Firefox.
2. Click **Start Recording** and select the screen, window, or tab to share.
3. Monitor the live preview and timer while recording.
4. Click **Stop Recording**, or end the session using the browser's native "Stop Sharing" control.
5. The recording is downloaded automatically as a `.webm` file.

## Built With

- **HTML** — page structure
- **CSS** — styling
- **JavaScript** — screen capture logic via the `getDisplayMedia` and `MediaRecorder` browser APIs
